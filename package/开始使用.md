# AC7 Integrated Mod — 0.6.0-beta.1（Beta 测试版）

**Beta 测试版，仅限单人游戏。进入多人对战前必须先停用 Mod**：AC7 多人模式的反作弊会把注入的代码判定为作弊。

把 AC8 Integrated 2.4.2 的鼠标飞控移植到 ACE COMBAT 7（Steam Build 9855922）。鼠标指定方向，Mod 协调飞机姿态飞向圆环；F4 在 **PEACE**（经典飞控）与 **WAR**（基于还原的 AC7 飞行引擎的精确控制）之间切换。可选安装 AC7Weapons 导弹模块（仅制导／完整强化两档）。

## 安装

1. 把整个文件夹解压到游戏目录之外，例如 `D:\Mods\AC7-Integrated`。
2. 关闭游戏，双击 **Start-GUI.cmd**。工具会从 Steam 库自动定位游戏；也可点“浏览…”选择包含 `Ace7Game.exe` 的文件夹。
3. 选择安装内容：
   - **仅鼠标飞控**：导弹保持原版。
   - **导弹仅制导**：只把 30 种玩家导弹的比例引导前置量调到 AC8 规则，速度、射程、伤害、近炸与外观保持原版。
   - **导弹完整强化**：按 AC8 完整规则调整玩家导弹的制导前置、速度与转向、锁定范围、近炸、爆炸范围与射程，外观保持原版。

   两档导弹改动都只在单人任务中生效，离开任务时恢复原值。也可在游戏关闭时编辑 `features.ini`：`features=mouse`、`features=guidance` 或 `features=full`（旧值 `weapons` 视为 `full`）。
4. 点击 **安装／更新**。工具先备份存档（`%LOCALAPPDATA%\BANDAI NAMCO Entertainment\ACE COMBAT 7`）与原有 Mod 文件，再逐个写入并校验。
5. 点击 **从 Steam 启动**，或照常从 Steam 启动。游戏内操纵类型选 **专家（Expert）**。

没有图形界面时可用 **Setup.cmd**。已有的 AC7 鼠标飞控安装（例如 Codex 0.4.0）只要文件未被改动，会被接管并更新，原有设置一并导入。发现不属于本工具的加载器或被修改的文件时，安装会停止，不覆盖任何文件。

## 单人与多人

- **停用 Mod（多人前）** 或 **Disable-Mod.cmd**：把加载器 `dwmapi.dll` 移到 `ue4ss\dwmapi.dll.disabled`，游戏以原版启动。
- **启用 Mod（单人）** 或 **Enable-Mod.cmd**：把加载器移回。
- 切换前先退出游戏。F8 只关闭飞控，不等于停用 Mod。这项检查只覆盖本 Mod，联机前请确认其他 Mod 也已停用。

## 设置

- **飞控设置**：灵敏度、启动飞控（PEACE／WAR）、机位、HUD、参考准星、制动辅助。准星默认由 GPU 在原生分辨率独立绘制（4K 下清晰）；“准星线宽”可在 0.5～2 倍之间调整，游戏中改 `config.ini` 的 `hud_line_width` 后按 F10 即时生效；也可在“HUD 绘制方式”里改为画进游戏 HUD。
- **键位设置**：自由观察、放大与手动接管检测键，需与游戏内操纵绑定一致。
- 设置保存在本包的 `MouseAim-Settings.ini` 与 `Keybindings.ini`，同时写入已安装的 `config.ini`，下次启动生效。保存时需关闭游戏。

## 游戏内按键

F1 设置面板 · F2 头盔瞄准 · F3 原生／拉远机位 · F4 PEACE／WAR · F7 HUD · Alt+F7 参考准星 · F8 飞控开关 · F9 回中 · F10 重读配置 · 按住 C 自由观察

## 卸载与排错

- **卸载（备份并清理）** 或 **Recover-Cleanup.cmd**：先备份，只删除内容与安装记录一致的文件；被修改的文件备份后保留，运行日志归档后保留。未完成的安装会先回滚。
- **收集日志** 或 **Analyze-Latest.cmd**：把运行日志复制到 `sessions\flight-*`，反馈问题时请附上整个文件夹。
- 出错时的诊断记录保存在 `diagnostics` 文件夹。

游戏更新后，版本校验会拒绝安装与启用，请等待新版整合包。基于 AC8 Integrated Mod 与 FletcherMiya/AC8-Mouse-Aim，第三方许可见 `licenses` 文件夹。
