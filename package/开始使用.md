# AC7 Integrated Mod — 0.7.0-beta.1（Beta 测试版）

**Beta 测试版，仅限单人游戏。进入多人对战前必须先停用 Mod**：AC7 多人模式的反作弊会把注入的代码判定为作弊。

把 AC8 Integrated 2.5.0 的鼠标飞控移植到 ACE COMBAT 7（Steam Build 9855922）。鼠标指定方向，Mod 协调飞机姿态飞向圆环。默认飞控为 **WAR**（基于还原的 AC7 飞行引擎做精确控制），F4 可切换到 **PEACE**（经典飞控）。可选安装 AC7Weapons 导弹模块（仅制导／完整强化两档）。

## 安装（两种方式，游戏内功能相同）

**安装版（推荐）**：运行 **AC7-Integrated-Setup-v0.7.0-beta.1.exe**。

- 安装到当前用户的 `%LOCALAPPDATA%\Programs\AC7 Integrated`，不需要管理员权限。安装程序没有代码签名证书，Windows 可能提示“Windows 已保护你的电脑”，点击“更多信息”→“仍要运行”。
- 游戏里已经装着便携版时，安装程序会询问是否导入它的设置、键位、安装内容、路径和附加 Mod，并把游戏中的 Mod 交给安装版管理（先备份，逐个校验）。便携版本身不会被改动。
- 之后从开始菜单打开 **AC7 Integrated**。启动器可以一键检查更新、检查并修复、回退到上一版本；卸载在 Windows 设置 → 应用。

**便携版**：把整个文件夹解压到游戏目录之外，例如 `D:\Mods\AC7-Integrated`，双击 **AC7 Integrated.exe**（或 `Start-GUI.cmd`）。设置保存在这个文件夹里。

在启动器中：

1. 点击“自动定位”，或用“浏览…”选择包含 `Ace7Game.exe` 的文件夹。
2. 选择安装内容：
   - **仅鼠标飞控**：导弹保持原版。
   - **导弹仅制导**：只把 30 种玩家导弹的比例引导前置量调到 AC8 规则，速度、射程、伤害、近炸与外观保持原版。
   - **导弹完整强化**：按 AC8 完整规则调整玩家导弹的制导前置、速度与转向、锁定范围、近炸、爆炸范围与射程，外观保持原版。

   两档导弹改动都只在单人任务中生效，离开任务时恢复原值。
3. 关闭游戏，点击 **安装／更新**。工具先备份存档（`%LOCALAPPDATA%\BANDAI NAMCO Entertainment\ACE COMBAT 7`）与原有 Mod 文件，再逐个写入并校验。
4. 点击 **从 Steam 启动**，或照常从 Steam 启动。游戏内操纵类型选 **专家（Expert）**。安装版从启动器启动时，会先核对程序文件和游戏中的 Mod，并在鼠标飞控就绪时显示 `[READY]`。

没有图形界面时可用 **Setup.cmd**。已有的 AC7 鼠标飞控安装（例如 Codex 0.4.0）只要文件未被改动，会被接管并更新，原有设置一并导入。发现不属于本工具的加载器或被修改的文件时，安装会停止，不覆盖任何文件。

## 单人与多人

- **停用 Mod（多人前）**：把加载器 `dwmapi.dll` 移到 `ue4ss\dwmapi.dll.disabled`，游戏以原版启动。
- **启用 Mod（单人）**：把加载器移回。
- 切换前先退出游戏。F8 只关闭飞控，不等于停用 Mod。这项检查只覆盖本 Mod，联机前请确认其他 Mod 也已停用。

## 设置

- **飞控设置**：灵敏度、启动飞控（默认 WAR）、机位、HUD、参考准星、制动辅助。准星由 GPU 在原生分辨率独立绘制（4K 下清晰）；“准星线宽”可在 0.5～2 倍之间调整，游戏中改 `config.ini` 的 `hud_line_width` 后按 F10 即时生效。
- **键位设置**：自由观察、放大与手动接管检测键，需与游戏内操纵绑定一致。
- **附加 Mod**：管理其他 UE4SS Mod。可以添加 zip 或文件夹（也可以直接拖进窗口），停用、启用或删除；改动会同步到游戏的 `ue4ss\Mods`，你手动放进游戏的 Mod 不受影响。压缩包里的 UE4SS 本体和 `.pak` 资源不会安装。只安装可信来源的 Mod。
- **保存飞行记录**（默认关闭）：开启后，每次飞行的 FE／Shadow 数据 CSV 会写入游戏的 `ue4ss\Mods\AC7MouseAim\Logs`，用于分析问题；关闭时只保留文本日志。下次启动游戏生效。
- 设置保存在本工具中（安装版在安装目录的 `data` 文件夹，便携版在本文件夹），同时写入已安装的 `config.ini`。保存时需关闭游戏。

0.7.0 起默认飞控为 WAR。之前保存过 PEACE 的设置，第一次运行时会改为 WAR（只改这一次）；之后再选 PEACE 会被保留。

## 游戏内按键

F1 设置面板 · F2 头盔瞄准 · F3 原生／拉远机位 · F4 WAR／PEACE · F7 HUD · Alt+F7 参考准星 · F8 飞控开关 · F9 回中 · F10 重读配置 · 按住 C 自由观察

## 更新、修复与卸载

- **检查更新**（启动器右上角）：安装版确认后在控制台中下载、校验签名和哈希并安装，游戏中的 Mod 随之更新；设置、键位和附加 Mod 都会保留，并保留上一版本以便回退。勾选“每天自动检查更新”后，打开启动器时最多每天检查一次。便携版会提示下载新版本。只读取 GitHub 发布信息，不上传任何数据。
- **检查并修复**（安装版）：检查程序文件、设置、游戏中的 Mod 文件和开始菜单项，能修复的自动修复；结束时可以回退到上一版本。
- **卸载（备份并清理）**：先备份，只删除内容与安装记录一致的文件；被修改的文件备份后保留，运行日志归档后保留。由本工具放进游戏的附加 Mod 也一并移除（仍保留在 Mod 库中）。未完成的安装会先回滚。
- **卸载安装版**：Windows 设置 → 应用 → AC7 Integrated → 卸载。会先卸载游戏中由安装版管理的 Mod；`data` 文件夹默认保留。
- **收集日志**：把运行日志复制到 `sessions\flight-*`，反馈问题时请附上整个文件夹。出错时的诊断记录保存在 `diagnostics` 文件夹。

游戏更新后，版本校验会拒绝安装与启用，请等待新版整合包。基于 AC8 Integrated Mod 与 FletcherMiya/AC8-Mouse-Aim，第三方许可见 `licenses` 文件夹。
