# 与其他 UE4SS Mod 一起使用（0.7.0 起）

[返回说明首页](../README.md) · [安装版](APP.md)

本整合包把 UE4SS 安装在游戏目录中。其他 UE4SS Mod 请在启动器的 **附加 Mod** 中添加：它们保存在本工具的 Mod 库里，由工具放进游戏的 `ue4ss\Mods`，和本包的 Mod 一起加载。

## 在启动器中管理

在启动器“设置与维护”中点击 **附加 Mod**：

- **添加**：点击“添加 zip…”选择下载的 Mod 压缩包，或点击“添加文件夹…”选择解压后的文件夹；也可以把 zip 或文件夹直接拖进窗口。
  - 会自动找到含 `Scripts\main.lua`（Lua Mod）或 `dlls\main.dll`（C++ Mod）的文件夹，常见的 `Mods\SomeMod\…`、`ue4ss\Mods\SomeMod\…` 打包方式都可以；一个压缩包里有多个 Mod 时一起添加。
  - 添加前会列出将要安装的 Mod 和注意事项，确认后才安装。压缩包里的 UE4SS 本体（`dwmapi.dll`、`UE4SS.dll`）和 `.pak` 资源不会安装。
  - 已有同名 Mod 时会替换，旧版本移到 `ue4ss-mods-removed`，原来的启用／停用状态保持不变。
  - 只支持 zip；7z、rar 请先解压，再用“添加文件夹…”。
- **启用／停用**：每个 Mod 右侧的按钮。停用会把 Mod 从游戏中移走，Mod 库里保留（文件夹名前加 `_`）。
- **删除**：Mod 从游戏中移走，库里的文件移到 `ue4ss-mods-removed`，需要时可以移回 `ue4ss-mods`。
- **同步到游戏**：每次改动后会自动同步；手动改过 Mod 库后可以点这个按钮。同步需要关闭游戏。
- **打开 Mod 库**：直接查看 `ue4ss-mods`（便携版在整合包目录下，安装版在安装目录的 `data` 下）。

列表显示每个 Mod 是否已在游戏中、是否等待同步。改动在下次启动游戏时生效。

## 游戏目录中的规则

- 工具在游戏的 `ue4ss\AC7-ExtraMods.json` 中记录自己放进去的每个文件及其校验值，并为每个 Mod 写入 `enabled.txt`。
- 移除时只删除记录中、且没有被改动过的文件；被改动的文件保留，并在结果中说明。
- 游戏里同名、但不是本工具放进去的文件夹不会被覆盖，列表中显示为冲突。你手动放进游戏的 Mod 不受影响。
- 安装／更新本整合包时会顺带同步附加 Mod；“卸载（备份并清理）”会移除游戏中由本工具放进去的附加 Mod，Mod 库保留，重新安装时再部署。

## 规则与兼容性

- **文件夹名**：只能使用英文字母、数字和 `_ . -`，不能与 `AC7MouseAim`、`AC7Weapons`、`shared` 同名。缺少 `Scripts\main.lua` 和 `dlls\main.dll` 的文件夹，以及包含文件系统链接（符号链接、目录联接）的文件夹，都不会安装，并说明原因。
- **共享库**：已附带 UE4SS 3.0.1 的 `shared` 库（UEHelpers），多数 Lua Mod 依赖它。
- **UE4SS 版本**：本包使用 UE4SS 3.0.1 Beta（`48e7edfe`）。其他 Mod 必须兼容这个版本；C++ Mod 尤其要用匹配的 UE4SS 版本编译，否则可能无法加载或导致游戏崩溃。
- **UE4SS 设置**：沿用本包的 `UE4SS-settings.ini`，控制台和 GUI 控制台默认关闭，热重载关闭。依赖这些功能的 Mod 可能表现不同。
- **Pak Mod**：只替换资源的 `.pak`（例如 `~mods`）由游戏自身加载，不经过 UE4SS，本工具不会改动它们。
- **按键冲突**：其他 Mod 使用的快捷键可能与本包的 F1–F10、Alt+F7 等冲突，请自行调整。
- **出现问题时**：先停用附加 Mod 再试，以确认问题是否来自附加 Mod。反馈时请注明你加入了哪些 Mod。

只安装可信来源的 Mod。仅限离线单人。
